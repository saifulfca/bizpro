# Bizpro

Deliverables for Bizpro (www.bizpro.com.bd), built from `Requirements_V2.docx`.

| Folder | What it is | Public? |
|---|---|---|
| `website/` | Static, multi-page website with a page for each business wing. See `website/README.md` for deployment and the launch checklist. | Yes, upload this folder only |
| `business-model/` | **Business Model & Concept Paper** (`.pdf` to read and share with partners, `.html` source to edit). Includes the internal delivery model, so it is confidential. | **No** |
| `brand/` | **Brand Profile**: logo, colours, typography, voice and application examples (`.pdf` + `.html`). Logo files are in `website/assets/img/`. | Internal |

All prices, volumes, statistics, names and testimonials are placeholders or hypothetical figures unless taken from the trade license.

To re-export a PDF after editing its HTML, open the `.html` file in Chrome → Print → Save as PDF (A4, margins "Default", background graphics on).
